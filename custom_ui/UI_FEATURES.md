## ✨ Key Features

### 1. **Code Generator** ⚡
Generate pytest test code from natural language prompts
- Multi-test class support
- AI-powered code generation (OpenAI, DeepSeek, Groq)
- Automatic test execution
- Allure report generation

### 2. **API Executor** 🚀
Execute API calls using natural language queries
- Semantic search for API endpoints
- Multi-query execution
- Real-time result display
- Comprehensive logging

### 3. **Swagger UI Scraper** 🌐
Extract API documentation from Swagger UI
- Automatic endpoint discovery
- Save to Excel format
- Support for multiple Swagger versions

### 4. **OpenAPI JSON Parser** 📄
Parse OpenAPI 3.0 specifications
- Schema extraction
- Endpoint documentation
- Excel export

### 5. **Configuration** ⚙️
Manage application settings
- AI model selection
- Persistent configuration
- Real-time updates

### 6. **Features Dashboard** ✨
Overview of all capabilities
- Feature status
- Quick navigation
- System information
